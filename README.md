A dark-themed, responsive personal portfolio website built with **HTML5, CSS3, and Vanilla JavaScript** to showcase my academic background, software development internship, certifications, technical skills, and full-stack projects.

---

## ✨ Key Features

- **Dynamic Hero Section:** Animated typing role switcher (*Software Engineer*, *Data Analyst*, *AI & ML Enthusiast*), social links, and direct PDF resume download.
- **Interactive Modals:**
  - **Certificate PDF Viewer:** Built-in modal (`#certificate-modal`) to preview internship, certification, and project PDFs without leaving the page.
  - **Local Project Video Player:** Custom modal (`#video-modal`) with playback controls and `Escape` / backdrop-click dismissal for project walkthroughs.
- **Scroll-Reveal & Active Navigation:** Intersection Observer section animations paired with scroll-spy navigation highlighting and a mobile hamburger menu.
- **Featured Project Showcase:** Structured project card with live deployment link, demo video trigger, certificate preview, and GitHub repository link.
